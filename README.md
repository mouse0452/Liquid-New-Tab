## 🌟 Overview
**Liquid New Tab** makes your browser's new tab screen more productive than just a new tab screen.

## 🚀 Key Features
* **A Large Clock:** Meet the big clock right on the new tab screen.
* **Convenient Widgets:** Take several actions, such as writing notes, checking the weather, and so on from the new tab page.
* **Shortcut Dock:** Quickly navigate to the page you want in the Shortcut Dock within the new tab screen.
* **Smooth Animation:** It is equipped with beautiful and soft animation.

## 📥 Installation & Usage
You can download the latest official release from the **Releases** section on the right.

1. Download the `.zip` file.
2. Unzip the Zip file and **keep the folder in a safe place.**
3. Open your Chrome-based browser and access `(browser_name)://extensions`.
4. Turn on the developer mode toggle and click 'Load decompressed extension' to select the decompressed folder and upload it.
5. On the new tab screen, click the 'Chrome Customization' button and click the 'Hide Footer' button.
6. Customize and enjoy your new tab page as you please!
